## 版本 C：完整长文版（适合图文详情页）

标题：毕设答辩第一名，我把整个项目开源了（附 Demo）

正文：

背景一句话：
现在的社交机器人检测基本靠"标注数据喂模型"，但 Bot 改个话术就失效。
我的思路反过来：不要标签，让图结构自己长出来。

技术路线（极简版）：
1. 多视图特征：LLM 压缩内容语义 + 行为统计 + 作息节律(DTW) + 关注拓扑
2. 自适应晚融合：缺失模态自动重归一化，不冤枉任何账号
3. 结构熵编码树：贪心合并，直到结构熵最小
4. 结果：18,743 用户的图上涌现 898 个社区，分成 4 类原型

核心指标：
| 方法 | 最大社区 | 密度 | 聚类系数 | 全局纯度 |
| K-Means | 2734 | 0.003 | 0.065 | 0.863 |
| 加权LPA | 5798 | 0.058 | 0.192 | 0.864 |
| 本文方法 | 283 | 0.165 | 0.337 | 0.864 |

亮点：
- 纯无监督，换个平台换批数据照样跑
- 完整工程：Python 包 12k 行 + 26 个 pytest 模块 + React 可视化
- Demo 部署在 GitHub Pages，点开就能玩
